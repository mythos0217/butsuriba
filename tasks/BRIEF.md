# ぶつりば 問題追加の指示（v0.4・網羅度の拡大）

あなたは大学物理の演習アプリ「ぶつりば」（/root/lemma-physics）の問題作成担当です。
目的は、各分野の **扱う題材の幅（網羅度）** と **全難易度の問題数** を広げること。

## 手順

1. /root/lemma-physics/tools/PROBLEM_GUIDE.md を全部読む（書式・品質・level 0 の作り方）。科目・分野の正式名は tools/physics_fields.py
2. 自分のタスクファイル（tasks/T??.json）を読む。各要素は `{"subject", "field", "need": {"難易度": 問題数}}`。**この数をちょうど作る**
3. 同じ分野の既存問題を確認する：`new/*.json` から subject と field が一致するものを抜き出し、theme と問題文に目を通す。
   **既存問題と題材・設定が重ならないようにする**。その分野の教科書の目次を思い浮かべ、まだ扱われていない節・典型問題・応用を優先して選ぶ（網羅度を上げるのが目的）
   - 新しく追加された分野（既存問題が 0 問）は、その分野の主要な題材を基礎から院試まで広く押さえる
4. Python で dict を作り json.dump で `new/more-T??.json` に書き出す（スクリプトは /tmp/gen-T??/）。tid は `T??-01` から
5. すべての答えを sympy / 数値計算で検算してから書く
6. `cd /root/lemma-physics && python3 tools/validate_new.py new/more-T??.json /tmp/v-T??` を「すべて OK」になるまで直す

## 難易度の目安

- 0 基礎：意欲的な高校生が問題文だけを頼りに解ける（大学の概念は問題文で定義してから使う）
- 1 標準：教科書の例題・本文の計算
- 2 演習：章末問題
- 3 院試：東大・京大などの物理学専攻の院試の小〜中問
- 4 院試難関：院試の大問レベル、または発展的なトピック（誘導付き）

## 注意

- tools/ と js/、既存の new/*.json は変更しない（ツールの不具合は直さず最終報告に書く）
- 入力用の答え：e はネイピア数（電気素量は q を使う）。変数は1文字＋添字。ギリシャ文字は omega や ω、ħ は hbar。
  変数名 C は「…+C」の形以外なら使ってよい。数値計算の答えは ≈ を付ける
- 答えの LaTeX で「文字の直後の括弧」（例 `gk(\rho_1-\rho_2)`、`wx(L-x)`）は照合ツールが関数と読むことがある。`(\rho_1-\rho_2)gk` のように並べ替える
- 自動採点できる形を優先し、記述（自己採点）は導出・証明が本質の小問だけにする

## 最終報告

問題数（難易度別）、扱った題材の一覧（1行ずつ短く）、検査結果の要約、気になった点だけ。
