# ぶつりば（大学物理）

ぶつりばは、答えを見せるのではなく、自力で立式して解ける頭をつくる大学物理の演習アプリ（試作版 v0.1）。
[Lemma 受験数学](https://github.com/mythos0217/lemma-math) と同じエンジン・同じ形式で、物理学科の学部〜院試の範囲を扱います。
iPhone・iPad のブラウザで動き、ホーム画面に追加するとアプリとして使えます（PWA）。

## 収録科目（学部での履修順）

物理数学 → 力学 → 振動・波動 → 解析力学 → 電磁気学 → 特殊相対論 → 熱力学 → 統計力学 → 量子力学 → 実験学 →
固体物理学 → 原子核物理学 → 相対論的量子力学 → 素粒子物理学 → 一般相対論 → 宇宙物理学 → 融合問題

科目ごとの分野（単元）は `tools/physics_fields.py` にあります（16科目＋融合、77分野）。

難易度は 0=基礎・1=標準・2=演習・3=院試・4=難関院試・5=最難関 の6段階。

## 受験数学版からの違い

- **物理の記号で答えを入力**：添字（`m_1`、`m1`、`ω_0`、`k_B`）、ギリシャ文字（`omega` でも `ω` でも可）、`hbar`/`ħ`、指数表記（`6.6e-34`、`6.6×10^(-34)`）
- **近似値の採点**：入力用の答えに `≈` を付けた数値は相対誤差 2% まで正解（有効数字3桁の計算向け。`≈1.2e5 (5%)` で幅を指定）
- **単位**：ラベルに `[s]` のように書くと入力欄に単位が出る。答えの後ろに同じ単位を付けて入力しても正解になる
- **計算トレーニング**：オーダー評価（物理定数で数値を出す）・ベクトル解析・行列と固有値・物理の積分（ガウス積分・ガンマ関数・ボース/フェルミ積分）・近似と展開・微分・積分
- **グラフの例**：減衰振動、共鳴曲線、有効ポテンシャル、プランク分布、フェルミ分布、井戸型ポテンシャルの束縛条件、平均場の自己無撞着方程式、相空間など。3D はメキシカンハット、双極子、波束など
- 学習記録は受験数学版と別の名前で保存するので、同じ端末で両方使っても混ざらない

そのほか（全分野ランダム／分野ごとの演習、復習の間隔調整、段階ヒント、自信度、自己採点、グラフ電卓、鳥の声かけ、ライト／ダーク、オフライン動作、記録の書き出し）は受験数学版と同じです。

## 問題管理表から問題を取り込む

問題は `ぶつりば問題管理表.xlsx`（問題一覧シート）で管理します。シートの形式は受験数学版と同じで、科目と分野の名前だけが物理用です。

```sh
pip3 install openpyxl sympy antlr4-python3-runtime==4.11
python3 tools/import_xlsx.py ぶつりば問題管理表.xlsx
node tools/check_answers.mjs data   # 入力用の答えが読めるか・自己整合するか
node tools/check_katex.cjs          # 数式がすべて描画できるか
```

`data/index.json` と `data/f-*.json` が作り直されます。そのあと `data` フォルダごとリポジトリにアップロードしてください。

### 新しい問題を作るとき

書き方の基準は `tools/PROBLEM_GUIDE.md`。JSON で作って検査し、問題管理表にまとめます。

```sh
python3 tools/validate_new.py new/ME.json     # 書式・KaTeX・入力用の答え・SymPy 照合・重複
python3 tools/make_xlsx.py                    # new/*.json → ぶつりば問題管理表.xlsx
```

### 入力用の答え（T列）の書き方

```
(1) ω：sqrt(g/l)                   ← 小問ごとに1行、ラベルは全角「：」
(2) 周期 [s]：≈2.01                ← ≈ は近似値（2%）、[ ] は単位
(3) μ：m_1 m_2/(m_1+m_2) ; E：hbar omega/2
(4) {1/2, -1/2}                    ← { } は順不同、( ) は順序あり、1:2 は比、0<x<1 は範囲
(5) 場合分け{ T<T_c → … | T>=T_c → 0 }
(6) 記述                            ← 証明・導出・説明は自己採点
```

変数は1文字（＋添字）だけ。`ab` は a×b。`e` はネイピア数、`E` は変数。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例：`butsuriba`、Public）
2. このフォルダの中身を**そのまま**リポジトリの直下にアップロード
3. 「Settings」→「Pages」→ Branch を `main` / `/ (root)` にして Save
4. 1〜2分後に `https://<ユーザー名>.github.io/butsuriba/` で開ける

更新したときは `sw.js` の `VERSION` を上げると、端末のキャッシュも入れ替わります。

## 構成

受験数学版と同じ（`js/` のエンジン、`data/` の問題、`tools/` の取り込み・検査）。物理版で足したもの：

```
tools/physics_fields.py   科目・分野・難易度の一覧
tools/make_xlsx.py        new/*.json → 問題管理表
tools/PROBLEM_GUIDE.md    問題の作り方
new/                      科目ごとの問題（検査済み JSON）
```

`js/content.js`（受験数学版の内蔵問題）は読み込みはしますが、物理版では出題しません。
