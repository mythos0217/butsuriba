# ぶつりば：問題の作り方（作成者向け）

対象は物理学科の学部2年〜院試受験者。答えを覚えるのではなく「自力で立式して解ける」力をつけるアプリの演習問題。
教科書の章末問題・院試問題の「核」を抜き出して新しく作る（数値・設定・問い方を変える。原文の丸写しはしない）。

## 1問の形（JSON 配列の1要素）

```json
{
  "tid": "ME-03",
  "subject": "力学",
  "field": "中心力と惑星運動",
  "level": 2,
  "theme": "有効ポテンシャルと円軌道の安定性",
  "minutes": 15,
  "q": "問題文（LaTeX）",
  "answer": "答え（LaTeX、小問ごとに (1) … (2) … と並べる）",
  "solution": "解答・解説（LaTeX）",
  "idea": "核となるアイデア（1〜2文）",
  "tags": "タグ1,タグ2",
  "input": "入力用の答え（下の書式）"
}
```

- `subject` / `field` は tools/physics_fields.py の名前と完全に一致させる
- `level`：0=基礎（定義の確認）, 1=標準（教科書の例題）, 2=演習（章末問題）, 3=院試, 4=難関院試, 5=最難関
- `minutes`：想定時間（分）。5〜40
- 文体は「である」調。句読点は「，」「．」（全角）。数式は `$...$`、別行立ては `\[...\]`
- 小問は `\begin{enumerate} \item … \item … \end{enumerate}`。番号は自動で (1)(2)… になる
- 使える文章命令：enumerate, itemize, tabular, \textbf, \emph, \quad, \\。それ以外の文章用 LaTeX 命令・図は使わない（図は言葉で説明する）
- 数式中は KaTeX で描ける命令だけ（\boldsymbol, \mathrm, \dfrac, \hbar, \nabla, \partial, \langle\rangle, \dagger, \bm は不可→\boldsymbol）
- 解説では最終的な答えを `\boldsymbol{...}` で太字に。段落は空行で区切る
- 数値には単位を `\,\mathrm{m/s}` の形で付ける

## 入力用の答え（`input`）

アプリはこの列で自動採点する。**できるだけ自動採点できる形にする**（証明・導出・説明だけの小問は `記述`）。

- 小問があるときは1行に1小問、行頭に `(1)` `(2)` … 小問の数と行数を一致させる。小問がない問題は番号なしの1行
- 1つの小問に答えが複数あるときは ` ; ` で区切る
- `ラベル：値`（全角コロン）でラベルを付ける。単位はラベルの `[ ]` に書く：`周期 [s]：≈2.01`
- 文字式：`sqrt(g/l)`、`m_1 m_2/(m_1+m_2)`、`hbar omega (n+1/2)`、`k_B T ln 2`、`omega_0^2`
  - 変数は「1文字（＋添字）」だけ：`m`, `v_0`, `k_B`, `m_e`, `ω` / `omega`, `ħ` / `hbar`
  - `ab` は a×b の意味。2文字以上の名前の変数は作れない（`Ry` などは不可 → 記号を変えるか数値で問う）
  - 使える関数：sin cos tan exp log(=ln) ln sqrt abs sinh cosh tanh arcsin arccos arctan、定数 pi, e
  - 問題文で与えた記号だけを使う。答えに出てくる文字はすべて問題文に出てくること
- 数値で、有効数字つきの計算結果は先頭に `≈`：`≈2.01`、`≈6.6e-34`（相対誤差2%まで正解）。許容幅を変えるなら `≈1.2e5 (5%)`
  - 厳密な数（`3/2`, `sqrt(3)/2`, `2pi`）は `≈` を付けない
- 指数表記は `6.6e-34` か `6.6*10^(-34)`
- 順不同の組 `{1/2, -1/2}`、順序のある組 `(a, b)`、比 `1:2:3`、範囲 `0<x<1`、場合分け `場合分け{ x<a → … | x>=a → … }`
- 証明・導出・説明は `記述`（自己採点）。`記述：要点` と書くと答え合わせで要点が出る

## 品質

- 物理として正しいこと。**答えは必ず自分で検算する**（python3 と sympy が使える。数値は計算して確かめる）
- 「答え」列の LaTeX と「入力用の答え」は同じ値にする（検査で SymPy 照合される）
- 易しすぎる穴埋めは避ける。各分野で、基本概念の確認1問＋演習2〜3問＋院試レベル1〜2問が目安
- 1問に小問を2〜4個つけ、誘導で山を登る形を基本にする（前の小問の結果を使う）
- 同じパターンの問題を重ねない

## 検査

```sh
python3 tools/validate_new.py new/<科目記号>.json /tmp/v-<科目記号>
```

「すべて OK」になるまで直す。SymPy 照合の「（照合できない）」は、答えの LaTeX と入力用の答えが本当に一致しているなら、
書き方を SymPy が読める形（`\frac{a}{b}`、`\sqrt{…}`）に寄せて解消する。
